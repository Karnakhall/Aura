Aura

Aura to projekt edukacyjny stworzony w Unreal Engine 5 podczas nauki programowania gier w C++.  
Jest to izometryczny RPG z systemem umiejętności opartym na Gameplay Ability System (GAS).  
Projekt służył do nauki mechanik rozgrywki, architektury kodu w UE5 oraz integracji C++ z Blueprints.

Funkcje projektu
- Podstawowy system poruszania i animacji postaci
- Implementacja umiejętności przy użyciu Gameplay Ability System
- Podstawowe interakcje w świecie gry
- Wykorzystanie śledzenia kolizji i raycastów
- Integracja C++ i Blueprintów

Cel projektu
Projekt powstał jako część procesu nauki i odtworzenia materiału z kursu online.  
Jego celem było zrozumienie zasad działania UE5, GAS oraz wdrażania logiki w C++.

Technologie
- Unreal Engine 5
- C++
- Gameplay Ability System

Status
Projekt edukacyjny – nie jest w pełni ukończoną grą.

English below

Aura is an educational project created in Unreal Engine 5 while learning C++ game development.  
It is an isometric RPG featuring a skill system built with the Gameplay Ability System (GAS).  
The project was used to practice gameplay mechanics, UE5 architecture, and C++ / Blueprint integration.

Features
- Basic character movement and animation system
- Ability implementation using the Gameplay Ability System
- Basic world interactions
- Collision tracing and raycasting
- Integration between C++ and Blueprints

Purpose
This project was created as part of a learning process and is a recreation of material from an online course.  
Its main purpose was to understand how UE5, GAS, and C++ gameplay logic work.

Technologies
- Unreal Engine 5
- C++
- Gameplay Ability System

Educational project – not a complete game.
